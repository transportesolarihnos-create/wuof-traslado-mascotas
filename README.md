# WUOF Traslado de Mascotas Rosario

Sitio estático preparado para GitHub + Cloudflare Pages.

## Publicación
1. Crear un repositorio en GitHub.
2. Subir todos los archivos de esta carpeta.
3. En Cloudflare: Workers & Pages > Create > Pages > Connect to Git.
4. Elegir el repositorio.
5. Framework preset: None.
6. Build command: dejar vacío.
7. Build output directory: /
8. Agregar el dominio trasladodemascotas.com.ar.

## Pendiente antes de campaña
- Reemplazar/agregar todas las fotos originales en /assets.
- Conectar Google Search Console.
- Configurar GA4 / Google Ads y eventos de conversión para WhatsApp y llamadas.
- Confirmar zonas de cobertura, horarios y servicios.
- Agregar URL exacta de Google Business Profile y reseñas verificadas.
